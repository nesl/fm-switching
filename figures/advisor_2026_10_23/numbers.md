# Advisor plots — plotted numbers and their sources (2026-10-23)

Generated by `experiments/figures/make_advisor_plots_2026_10.py` at commit `28adaa1f0942`. CPU only; no GPU was used and no inference was run.

Every value in this file is **computed from the committed result files**. The *report* column names the committed report the value should match, and *report value* is the figure printed there. A difference larger than the stated tolerance (0.1 pp by default) is flagged as a MISMATCH and is listed below rather than silently reconciled.

Confidence intervals: S-EMBER uses the video-clustered bootstrap imported from `experiments/sember/study_o_q4_analyze.py` (2,000 resamples, seed 0); ERQA and MV-RoboBench use a paired question-level bootstrap (2,000 resamples, seed 0). AUROC CIs reuse `experiments/erqa/r4_analyse.py`'s own `auroc` and `boot_ci` and consume the random stream in that script's order, so they reproduce its published intervals digit for digit.

## Notes on denominators and definitions

- **S1** — ERQA 8B **is** available (StudyQ arms D = 8B-Instruct and C = 8B-Thinking, A6000 HF sdpa) and is included. MV-RoboBench has no 8B arm in the repository.
- **S2** — The R1 K2 request records store `completion_tokens` but no think-token count, so the 'median reasoning tokens' bar for cloud 32B-T on S-EMBER is completion tokens (139). study_r1_cloud32b_sember.md reports think tokens median 135 and completion tokens median 139 for the same cell — the bar is the latter, and it is the only Thinking arm in this figure not measured as think tokens.
- **S6** — All ten cells are scored on the same paired set of n=839 questions (the intersection with no HTTP-400 over-context error), so one scatter uses one denominator. Each report scores its own cells on its own denominator (RH1/RH3 on 845, RH4 on its paired 839), so the per-cell accuracies below differ slightly from the report values; both are listed.

## Deliberate differences from the reports

These are specified differences, not discrepancies:

- **S4 cloud tier.** The escalation curves and the oracle crossings for ERQA and MV-RoboBench use **arm C (32B-Instruct)** as the cloud tier, as specified for this deck. `reports/r4_device_signals_prep.md` uses **arm D (32B-Thinking)**, so its escalation table (gap-closed −0.261 on ERQA/Instruct, etc.) is not the same quantity and is not cross-checked here. The AUROCs are device-side only and so are unaffected — all 23 reproduce exactly.
- **S2 reshuffling.** `% of answers changed by thinking` is plotted as the fraction of questions whose predicted letter changed. The S2 and R reports use the phrase "answers changed by thinking" for the McNemar discordance b+c (correctness flips), a smaller quantity. Both are recorded; the b+c rows are the ones cross-checked.
- **S6 denominator.** All ten history cells are scored on one common paired set so a single scatter is internally consistent. StudyRH4's table uses the same paired set and matches exactly; H1a, H1b, C and H1c are only published on 845, so those four rows carry a widened tolerance and are labelled.
- **S3 denominators.** The device panel uses the pre-registered `qt > 120 s` subset (n = 678) as `reports/device_tier_accuracy_llamacpp.md` does; the cloud panels use the denominators of R1 and RH4. Each panel states its own n.
